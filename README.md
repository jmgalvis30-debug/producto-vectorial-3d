# Producto vectorial en 3D

Proyecto académico para calcular el producto vectorial de dos vectores en R³ y visualizar su representación geométrica.

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: estilos y diseño visual.
- `script.js`: operaciones matemáticas, procedimiento y gráfica interactiva.

## Cómo ejecutar
1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador moderno (Chrome, Firefox o Edge).
3. Ingresa las componentes de los vectores A y B.
4. Pulsa **Calcular producto vectorial**.
5. Arrastra sobre la gráfica para rotarla y usa la rueda del mouse para cambiar el zoom.

No requiere instalación de dependencias ni conexión a internet.

## Fórmula utilizada
Si A = (Ax, Ay, Az) y B = (Bx, By, Bz), entonces:

A × B = (Ay·Bz − Az·By, Az·Bx − Ax·Bz, Ax·By − Ay·Bx)
